# Kydon Website - Sanity Studio

This is your content management system (CMS) for the Kydon website.

## Quick Start

### Step 1: Install Dependencies

Open Terminal (Mac) or PowerShell (Windows) and navigate to this folder:

```bash
cd kydon-sanity-studio
npm install
```

### Step 2: Start the Studio Locally

```bash
npm run dev
```

The studio will open at **http://localhost:3333**

### Step 3: Deploy Online (Recommended for Team Access)

```bash
npm run deploy
```

When prompted, choose a hostname (e.g., `kydon-cms`).
This creates a permanent URL like **kydon-cms.sanity.studio** that anyone can access!

## How to Edit Content

1. Open the studio (localhost:3333 or your deployed URL)
2. Click on a content type in the left sidebar
3. Click **"+"** to create new content, or click existing content to edit
4. Fill in the fields
5. Click **Publish** (green button, top right)
6. Your website updates automatically within 60 seconds!

## Adding Team Members to Sanity

1. Go to [sanity.io/manage](https://www.sanity.io/manage)
2. Select your project
3. Click **"Members"** → **"Invite member"**
4. Enter their email address
5. They can now access the CMS!
